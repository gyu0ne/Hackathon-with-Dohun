# 실제 촬영 문서 OCR 평가

## 데이터

[Inv3DReal](https://felixhertlein.github.io/inv3d/)의 실제 스마트폰 촬영본을 사용한다. 이 데이터에는 원근, 말림, 접힘, 구김과 밝은 조명, 색조 조명, 그림자 조건이 있으며 문서별 단어 정답이 포함된다.

다운로드한 원본은 `research/external_photos/inv3d`에 두고 Git과 Docker build context에서 제외한다.

| 파일 | 크기 | SHA-256 |
|---|---:|---|
| `inv3d_real_part_1_of_2.zip` | 68,622,760 bytes | `0a37e0d5a9abab5d3ff533366f6d6603729573a51a4519e57810e7e4cb6d644e` |
| `inv3d_real_part_2_of_2.zip` | 76,063,288 bytes | `1feb06d6f5281daed497bb40d46368a74efc9c4b7db20c66b263f98d09318421` |

평가기는 ZIP을 풀지 않고 필요한 JPEG와 `ground_truth_words.json`만 스트리밍한다. 최종 확대 평가는 서로 다른 템플릿 8개에서 변형 6종과 조명 3종을 순환 배정한 48장을 사용한다.

## 지표

- `reading_order_cer`, `reading_order_wer`: 정답과 OCR의 전체 읽기 순서까지 평가한다. 표·다단 문서에서는 순서 차이 때문에 과대 측정될 수 있다.
- `word_f1`: 읽기 순서를 무시하고 중복 개수까지 반영한 단어 보존율이다.
- `numeric_f1`: 날짜, 금액, 전화번호 등 숫자 토큰의 보존율이다.
- `ocr_ms`: 전처리를 포함한 OCR 실행 시간이다.

화면의 모델 확신도는 정답 정확도가 아니다. 따라서 단독 성능 지표로 해석하지 않고, 정답을 보지 않는 후보 선택 규칙 중 하나로만 비교한다.

## 2026-08-12 실험 결과

동일한 `korean_PP-OCRv5_mobile_rec` 인식 모델과 CPU 환경에서 비교했다.

### 후보 탐색

| 후보 | 문서 | 단어 F1 | 숫자 F1 | 평균 OCR 시간 | 판단 |
|---|---:|---:|---:|---:|---|
| 원본, 검출 한계 960 | 12 | 90.70% | 91.99% | 4.84초 | 기준 |
| 자체 원근 보정, 960 | 12 | 91.20% | 92.32% | 4.78초 | 효과가 작고 2장에만 작동 |
| Paddle UVDoc 언워핑, 960 | 12 | 93.75% | 93.73% | 7.71초 | 정확하지만 느림 |
| 원본, 검출 한계 1536 | 12 | **94.18%** | **95.32%** | **6.38초** | 기본값 채택 |

추가 ablation에서 강제 조명 정규화는 6장 단어 F1을 89.61%에서 87.98%로 낮췄다. 서버 검출 모델은 CPU 컨테이너에서 첫 추론 전에 프로세스가 종료되어 MVP 후보에서 제외했다.

### 48장 확대 검증

| 후보 | 단어 F1 | 숫자 F1 | 순차 CER | 평균 OCR 시간 | 단어 F1 승/패/동률 |
|---|---:|---:|---:|---:|---:|
| 1536px 원본 | 85.83% | 81.72% | 57.19% | 6.24초 | 기준 |
| 1536px UVDoc | **89.00%** | **84.67%** | **55.77%** | 8.89초 | 33 / 11 / 4 |

UVDoc의 평균 이득은 단어 F1 +3.17%p, 숫자 F1 +2.95%p였다. 다만 문서별 효과가 같지 않고 11장에서는 단어 F1이 낮아졌다.

정답을 보지 않는 자동 선택 규칙도 비교했다.

| 선택 규칙 | 단어 F1 | 숫자 F1 | UVDoc 선택 | 정답 기준 최선과 일치 |
|---|---:|---:|---:|---:|
| 항상 원본 | 85.83% | 81.72% | 0/48 | 15/48 |
| 항상 UVDoc | 89.00% | 84.67% | 48/48 | 33/48 |
| 높은 모델 확신도 | 88.66% | 84.86% | 29/48 | 26/48 |
| 더 많은 인식 단어 | **89.13%** | **84.98%** | 33/48 | **38/48** |
| 더 많은 인식 글자 | 89.12% | 84.93% | 35/48 | 38/48 |
| 정답을 보는 이론적 상한 | 89.38% | 85.82% | 33/48 | 48/48 |

단어 수 선택은 좋은 연구 후보지만, 매번 두 OCR을 모두 실행해야 해 평균 OCR 시간이 약 15.13초가 되고 UVDoc 좌표가 원본 이미지의 출처 하이라이트 좌표와 직접 일치하지 않는다. 또한 이 표본은 영어 송장이므로 한국어 촬영 문서에 그대로 일반화할 수 없다.

따라서 오류 없는 해커톤 MVP의 실제 사용 경로는 원본을 1536px까지 보존해 한 번만 OCR하고 원본 좌표 하이라이트를 유지한다. UVDoc은 정확도 우세 후보로 `/test`의 필터 ON/OFF 실험군에 제공한다. 한국어 실사진에서 이득과 좌표 매핑을 검증한 뒤 기본 경로 승격 여부를 결정한다.

## 재현

```powershell
docker run --rm `
  -v "${PWD}:/app" `
  kcode-public-doc-mvp `
  python -m research.scripts.evaluate_photo_filters `
    --data-dir research/external_photos/inv3d `
    --archive-limit 2 --templates-per-archive 4 `
    --variant raw --variant paddle_unwarp `
    --det-limit 1536 --det-model mobile `
    --output research/results/photo_filter_inv3d_48.json
```

상세 결과는 `research/results/photo_filter_inv3d_48.json`에 있다. 이 결과는 영어 송장 촬영본의 전처리 효과를 비교한 것이다. 한국어 인식 모델 자체의 평가는 AI-Hub 공공행정문서 세트와 분리해서 해석한다.
